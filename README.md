# Event Booker

Event Booker is a Django-based web app for browsing concerts, booking tickets, and following your favorite bands. Features include viewing events and tours, managing tickets, and user authentication. Built with Django 5, Bootstrap 5, and SQLite (dev).  


## Features
- View events and tours
- Browse artists
- Book and manage tickets
- User authentication
- Admin management of events, tours, and artists
- 
## Setup
1. Clone repo and create a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`.
3. Configure `.env` with secrets.
4. Run migrations: `python manage.py migrate`.
5. Start server: `python manage.py runserver`.
